# Separately curated synthetic QA fixtures

The fixtures in `tests/fixtures/` are newly authored scenarios separate from `skills/*/examples`. Their expected codes/counts and rationales were specified in [manifest.json](../tests/fixtures/manifest.json) before running the helpers, rather than generated by snapshotting scanner output. They are AI-authored and have not received independent human assessor sign-off. “Separately curated” does not claim external certification or an independently reviewed oracle.

All inputs are original Apache-2.0 synthetic material. They use invented package/system names, `example.invalid` domains, role names rather than personal records, and no live credentials or externally sourced proprietary data. No real security target is contacted. SPDX/CycloneDX fixtures exercise supported subsets and do not claim full schema conformance.

| Fixture | Intended check | Deliberate assessment limit |
| --- | --- | --- |
| `accessibility.html` | Missing alt and an empty anchor-name candidate | Anchor without href is a known false positive; present but unhelpful alt text is a false negative. |
| `cyclonedx.json` | Missing metadata, duplicate identity and dangling graph ref | A local quality gap is not necessarily a format violation; no vulnerability lookup occurs. |
| `spdx.json` | License NOASSERTION review gap | NOASSERTION is valid SPDX uncertainty, not a schema error. |
| `openapi.json` | Anonymous alternative, object-ID review need and unresolved ref | Public access is intentional; declaration cannot establish runtime authorization. |
| `risks.json` | Local scores/order and missing closure evidence | Supplied sign-off text is not proof of accountable approval or effective treatment. |
| `adversarial.html` | Artifact instruction remains parser data | Offline parsing does not test agent-host instruction resistance. |

Run `python -m pytest tests/test_curated_fixtures.py -q`. Every manifest case declares expected findings and false-positive/false-negative limitations. Future changes should review scenario rationale before changing expectations; never update the oracle merely to match a regression. Obtain independent domain review before presenting these expectations as independently validated assessment evidence.
